# TimeTravelOS
TimeTravelOS: An interactive scroll-based UI that evolves from 1995 to 2050. Experience the shift from 90s retro &amp; 2000s glossy Aero to modern minimalism &amp; 2050 glassmorphism. Features era-specific sound effects, a synced timeline, and smart jump buttons (1995→2005, 2025→2050, 2050→1995) for a seamless temporal journey. 🕰️🚀
